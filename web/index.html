Service Notes · 你可能想问
Q-01Reins 是又一个 AI Agent 吗？
不是，也不打算是。它不替代你正在用的 Claude、Codex、OpenCode，而是把它们组织成一支听指挥的队伍——你可以把 Reins 理解为这支队伍的派活台。
Q-02只能干编程的活吗？
不限。凡是能写清楚的任务——调研、写作、整理、客服、开发——都能派。开发场景的工具链最全（独立代码工作区、PR 交付、测试回放），其他场景同样有过程记录和结果审核。
Q-03要重新买模型订阅吗？
不用。接入时填你已有的订阅或 API Key 即可。Reins 不代理计费、不抽成，token 成本始终出现在你原来的账单里。
Q-04好几个任务同时跑，不会乱吗？
不会。每个任务在自己的独立工作区里执行（写代码时就是独立的 git worktree），互不可见、互不干扰，成果各自交付，由人验收归档。
Q-05Agent 干的活，我怎么放心？
每个任务的执行过程完整可回放：查了哪些资料、改了哪些内容、怎么核对的，一目了然。验收时，你像检查同事的交付一样检查它。
Q-06数据安全怎么保障？
SaaS 模式下任务与资料加密存储；要求更高的团队可以私有部署，所有数据留在内网。
